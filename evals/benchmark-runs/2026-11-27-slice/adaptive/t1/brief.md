# Task 1: Landing page

Build a single-page landing page for **Lumen**, a note-taking app.

Requirements:
- One `index.html` (CSS may be inline or in `styles.css`; JS optional). No frameworks, no build step.
- Sections, in order: hero (name, tagline, call-to-action link), features (exactly 3), pricing (exactly 3 tiers: Free, Pro, Team), FAQ (at least 3 questions), footer.
- Responsive (meta viewport + at least one media query) and accessible (html lang attribute, exactly one h1, alt text on any images).
